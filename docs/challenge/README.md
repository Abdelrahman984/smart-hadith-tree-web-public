## قبل التسليم

1. الرابط الحي يفتح، والمستودع **عام** (يُنشر بـ `scripts/publish-public.ps1`).
2. العرض يُراجع في PowerPoint ويُصدَّر PDF.
3. الفيديو مسجَّل ومرفوع.
4. التسليم عبر البوابة مع الاحتفاظ برسالة التأكيد. عند عطل: `info@IslamicAIch.org` مع رقم المشاركة.
